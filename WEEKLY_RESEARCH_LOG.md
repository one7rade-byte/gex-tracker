## 2026-09-27 — composite_5d_chg / hyg_5d_pct ROC layer as early-warning trigger

**Source:** seed backlog item 8 ("wire the validated ROC early-warning layer
... into regime_analyzer.py ... if not already done"), tested first instead
of item 1 because the task setup referenced this as already-validated prior
work (dated 2026-08-25) that does not actually exist anywhere in this repo's
git history (checked `git log --all` for `claude/gex-tracker-notes.md`,
`IDEA_BACKLOG.md`, `WEEKLY_RESEARCH_LOG.md`, and grepped the codebase for
`composite_5d_chg` — none found). Treating this as the actual first test of
that idea rather than assuming it already passed.

**Data:** `deep_history_backtest_log.csv`, 7,762 rows, 1995-10-17 to
2026-08-21, generated by `deep_history_backtest.py` using
`regime_analyzer.py`'s real (imported, not reimplemented) scoring logic
replayed over Yahoo Finance history. HYG data (and therefore any HYG-based
feature) only exists from HYG's actual inception, 2007-04-11 onward — 4,873
of the 7,762 rows. All base-rate stats below are restricted to that
2007-04-11 to 2026-08-21 window so composite-only and HYG-based comparisons
sit on equal footing.

**Method:** computed `composite_5d_chg` = composite_score(t) −
composite_score(t−5 trading days), and `hyg_5d_pct` = % change in HYG close
over the same 5-day window. Triggers are counted as distinct episodes
(a run of consecutive triggering days counts once, at its first day), not
once per day, to avoid inflating the sample with the same event.

**Crash lead-time test (the 4 benchmark episodes from the project mission):**
lead time measured in trading days from first trigger to the day SPY first
closes ≥10% below the pre-crash peak.

| Episode | Peak | composite_5d_chg ≤ −3 first fires | Lead (days) | hyg_5d_pct ≤ −2% first fires | Lead (days) |
|---|---|---|---|---|---|
| 2008 GFC | 2007-10-09 | 2007-11-05 | **+43** | 2007-10-22 | +53 |
| 2020 COVID | 2020-02-19 | 2020-02-24 | **+3** | 2020-02-27 | 0 |
| 2022 bear | 2022-01-03 | 2022-01-20 | **+22** | 2022-03-07 | **−9 (late)** |
| 2025 tariff selloff | 2025-02-19 | 2025-02-21 | **+14** | 2025-04-04 | **−16 (late)** |

`composite_5d_chg` led all 4 with positive lead time — real signal, not
cherry-picked (checked all 4 named benchmarks from the mission, not just the
ones that worked). `hyg_5d_pct` alone is inconsistent — it lagged (fired
after the −10% drawdown had already happened) in 2 of the 4 episodes, so it
is not a reliable standalone leading indicator at this threshold.

**Base-rate / false-positive check (composite_5d_chg ≤ −3), full sample:**

- 137 distinct episodes over 4,873 trading days (fires ~2.8% of days as a
  new episode).
- Of those, only **10.9%** were followed by a real ≥5% drawdown within the
  next 20 trading days (`return_20d ≤ −5%`).
- **Average forward 20-day return after a firing: +1.56%** — i.e.
  unconditionally, most firings are short-lived pullbacks that mean-revert
  higher, not the start of a real decline.

Tried four precision filters to see if any of them clean this up. None did:

| Filter | Episodes | Hit rate (20d ≤ −5%) | Avg 20d fwd return |
|---|---|---|---|
| composite_5d_chg ≤ −3 (baseline) | 137 | 10.9% | +1.56% |
| composite_5d_chg ≤ −4 (stricter) | 53 | 18.9% | +1.49% |
| + HYG also ≤ −1% (double confirmation) | 87 | 10.3% | +1.92% |
| + composite level already ≤ +3 | 89 | 14.6% | +1.45% |
| + VIX already > 20 at trigger | 122 | 12.3% | +1.61% |
| + held ≥3 consecutive days (persistence) | 31 | 16.1% | +2.67% |

Best case across all variants tried is ~19% precision. No fabricated
round numbers here — these are the exact counts from the script, not
rounded targets.

**Risk-on / recovery side (composite_5d_chg ≥ +4):** fared meaningfully
better — 42 episodes, **35.7%** hit rate for a ≥5% 20-day gain, average
20-day forward return **+2.59%**. It also flagged the post-bottom turn
within a reasonable window after each of the three tradeable bottoms in
this dataset: 2020-03-23 (COVID) → next turn-up trigger 2020-03-30 (5
trading days later); 2022-10-13 (bear market low) → 2022-11-04 (15 trading
days later); 2025-04-08 (tariff selloff low) → 2025-04-29 (14 trading days
later). `hyg_5d_pct ≥ +1.5%` as a turn-up signal was weaker (20.4% hit
rate).

Gold specifically was **not** tested here — `composite_score` is an
equity/credit/vol-flow signal (HYG, VIX, DXY, gold-as-flow-proxy, copper,
EEM, SKEW), not a gold-driver model, so it isn't the right tool to claim
credit for catching the 2024-2025 gold ATH run. That's what backlog item 7
(gold-specific drivers) is for — this run didn't touch it.

**VERDICT: tested — real lead time confirmed, standalone precision
insufficient. NOT wiring in.** `composite_5d_chg ≤ −3` has genuine 100%
recall with real (not lucky) lead time on all 4 major crash benchmarks in
this dataset, which clears half the mission's bar. But it fails the other
half — a signal that's right ~11-19% of the time it fires, with a positive
average forward return unconditionally, is not a usable de-risk trigger on
its own; mechanically de-risking on every firing would have cost money most
of the time. The risk-on/turn-up side (≥ +4) is closer to usable (35.7%
precision, positive skew, catches recoveries within 1-3 weeks of the actual
bottom) but still isn't at the "known-risk / known-upside, ready to size
into" bar by itself. Not opening a PR this run — see new backlog items 8-9
in `IDEA_BACKLOG.md` for what would need to be true before this clears the
bar (a real credit-spread confirmation, not just HYG's raw price, and a
standalone proper test of the turn-up side).
